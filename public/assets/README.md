# Assets Folder

Place your assets in this directory (`/public/assets`):

- **Light Logo Variation**: e.g., `logo-light.svg` or `logo-light.png`
- **Dark Logo Variation**: e.g., `logo-dark.svg` or `logo-dark.png`
- **Animated Hero Asset**: e.g., `hero-animated.mp4` / `hero-animated.webm` / `hero-animated.gif` (or an image sequence)

Any file placed in `/public/assets/<filename>` is directly accessible at the URL path `/assets/<filename>`.
